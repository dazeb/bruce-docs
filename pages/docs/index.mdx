## About BRUCE

BRUCE (Big Brother Ultimate Communication Equipment) is a professional-grade wireless security research platform built around ESP32 microcontrollers. It's designed to be Flipper Zero's powerful big brother, offering:

- **Extended Range**: Multiple RF modules for long-range communication
- **More Protocols**: WiFi 6, BLE 5.3, Sub-GHz, LoRa, NFC/RFID
- **Standalone Operation**: Battery-backed with touchscreen interface
- **Professional Grade**: Robust architecture with proper bus isolation

## Project Philosophy

Bruce embodies the **shark** - powerful, serious, dominant, and protective. While Flipper Zero is the friendly dolphin for learning and exploration, BRUCE is the apex predator for serious security research.

### Design Principles

1. **Bus Isolation**: 3 separate SPI buses prevent conflicts
2. **Modularity**: Hot-loadable plugins for extensibility
3. **Reliability**: Proper power management and error handling
4. **Openness**: MIT licensed, community-driven development
