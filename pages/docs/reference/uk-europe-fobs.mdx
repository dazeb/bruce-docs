## Executive Summary

UK and European RF fobs predominantly operate on **433.92 MHz** (ISM band) for car keys, garage doors, and gate remotes. The **868 MHz** band is used for advanced wireless sensor networks and some modern BMW vehicles (though BMW has recently returned to 434 MHz).

### Critical Frequencies for Bruce 🦈

1. **433.92 MHz** ⭐⭐⭐⭐⭐ - **PRIMARY TARGET**
   - 90%+ of UK/EU fobs operate here
   - Car keys, garage doors, gates, alarms
   - ISM band: 433.050-434.790 MHz

2. **868 MHz** ⭐⭐⭐ - **SECONDARY TARGET**
   - Modern wireless sensor networks
   - Some BMW vehicles (CAS3/CAS4 older models)
   - Less crowded than 433 MHz

3. **315 MHz** ⭐ - **MINIMAL IN EUROPE**
   - Rarely used in UK/EU (US/Canada standard)
   - Some imported vehicles only

## UK/EU Regulatory Environment

### ISM Band Regulations

**433.92 MHz Band**:
- **Frequency Range**: 433.050 - 434.790 MHz (ITU Region 1)
- **Legal Power Output**: Maximum 10 mW ERP (Effective Radiated Power)
- **Duty Cycle**: Limited transmission time to prevent interference
- **Antenna Requirements**: Integral, non-removable antenna in some countries
- **License**: License-free (no authorization required)
- **Regulator**: Ofcom (UK), ETSI (EU)

**868 MHz Band**:
- **Purpose**: Wireless sensor networks, telemetry
- **Advantage**: Less crowded than 433 MHz (recommended where available)
- **Usage**: Exclusively reserved for communication between wireless sensor networks

**⚠️ LEGAL NOTE**: Communications equipment in ISM bands must **tolerate any interference** from other ISM devices. Users have **no regulatory protection** from interference in these bands.

## Car Key Fob Protocols

### European Car Manufacturers

#### **KeeLoq / HCS Series** (Microchip Technology)
**Used By**: Chrysler, Fiat, Ford, Mercedes-Benz, Volvo, Volkswagen Group, Jaguar, Honda, Toyota, GM

**Technical Specs**:
- **Frequency**: 433.92 MHz (Europe), 315 MHz (some markets)
- **Protocol**: Rolling code (code hopping)
- **Encryption**: KeeLoq block cipher (64-bit)
- **IC Series**: HCS101, HCS2XX, HCS3XX, HCS4XX, HCS5XX, MCS31X2
- **Security**: Rolling/hopping code changes after each use
- **Developed**: Mid-1980s, acquired by Microchip in 1995

**How Rolling Code Works**:
1. Transmitter sends encrypted code + counter value
2. Counter increments after each button press
3. Receiver validates code and counter (must be within sync window)
4. Old codes are rejected to prevent replay attacks

**KeeLoq Vulnerabilities** (for research purposes):
- Original KeeLoq cipher designed in 1980s/90s - considered insecure by modern standards
- Known cryptanalytic attacks exist (side-channel analysis)
- Newer systems use "Ultimate KeeLoq" with AES-128 cipher replacement

**European Manufacturers Using KeeLoq**:
- **Fiat** (Italy)
- **Mercedes-Benz** (Germany) - older models
- **Volvo** (Sweden) - older models
- **Volkswagen Group** (Germany) - Audi, VW, SEAT, Skoda
- **Jaguar** (UK)
- **Ford Europe** (UK/Germany)

#### **BMW-Specific Frequencies**

**BMW Model Variations**:
- **433.9 MHz**: CAS4 system with EWS4 security level
- **433.2 MHz**: FEM/BDC system (CAS4+) with EWS5 security level
- **868 MHz**: CAS3 system (older models, pre-2013)
- **Trend**: BMW moving back to 434 MHz in newer models (2020+)

**CAS System Evolution**:
- CAS1/CAS2: 433 MHz
- CAS3: 868 MHz (2005-2012)
- CAS4: 433.9 MHz (2013-2019)
- CAS4+: 433.2 MHz (2017+)

#### **Other Proprietary Systems**

**Hitag (NXP)**:
- Used by: Volkswagen Group, BMW (older)
- Variants: Hitag1, Hitag2, HitagS
- Frequency: 125 kHz (passive RFID) + 433 MHz (active)

**DST40 (Texas Instruments)**:
- Used by: Various European manufacturers
- Designed: 1990s (considered insecure by modern standards)

**Megamos Crypto**:
- Used by: Audi, Porsche, Volkswagen, Bentley, Lamborghini
- Frequency: 433 MHz
- Known vulnerabilities exist (for research)

## Garage Door & Gate Remote Protocols

### Major European Brands

#### **CAME (Italy)** ⭐⭐⭐⭐⭐
**Market Leader** - Most common in UK/EU

**Protocols**:
1. **CAME 12bit 433MHz** (Fixed Code)
   - Frequency: 433.92 MHz
   - Bits: 12
   - TE (Time Element): 320 μs
   - Repeat: 3-5
   - Modulation: ASK/OOK
   - Total Combinations: 4,096 (2^12)
   - Brute-Force Time: ~72 seconds

2. **CAME TOP 432EV** (Rolling Code)
   - Frequency: 433.92 MHz
   - Encryption: AES-128 (secure)
   - Used in newer systems (2015+)

**CAME Popularity**:
- #1 in UK, Italy, France, Spain
- Widespread in Eastern Europe
- Used by professional installers

#### **NICE (Italy)** ⭐⭐⭐⭐
**Second Most Common**

**Protocols**:
1. **NICE FLO (Floating Code)**
   - Frequency: 433.92 MHz
   - Bits: Variable (12-24)
   - Modulation: ASK/OOK
   - Security: Rolling code

2. **NICE SMILO** (Universal)
   - Compatible with fixed and rolling code systems
   - Frequency: 433.92 MHz

**NICE Market**:
- #2 in UK/EU garage door market
- Strong presence in residential installations

#### **BFT (Italy)** ⭐⭐⭐
**Premium Brand**

**Protocols**:
1. **BFT MITTO Series** (Rolling Code)
   - Frequency: 433 MHz
   - Channels: 2 or 4 button
   - Security: Rolling code (modern systems)
   - Used for: Gates, garage doors, barriers, automated devices

**BFT Market**:
- Premium commercial/industrial installations
- Common in high-security environments

#### **Other European Brands**

**Hörmann (Germany)** ⭐⭐⭐:

**Somfy (France)** ⭐⭐:

**Sommer (Germany)** ⭐⭐:

#### **Universal Remote Compatibility**

**Frequency Range**: 280-868 MHz

## Alarm System Protocols

### UK/EU Wireless Alarm Systems

**433 MHz vs 868 MHz Comparison**:

| Feature | 433 MHz | 868 MHz |
|---------|---------|---------|
| **Crowding** | Very crowded (garage remotes, toys, sensors) | Less crowded (recommended) |
| **Interference** | High risk | Lower risk |
| **Range** | Shorter (more interference) | Longer (less interference) |
| **Usage** | Legacy systems, budget alarms | Modern sensor networks, premium alarms |
| **Recommendation** | Avoid if possible | Preferred for new installations |

**Common Alarm Protocols**:
- **Contact ID**: Industry standard alarm reporting
- **DSC PowerG**: 868 MHz, encrypted (AES-128)
- **Ajax Systems**: 868 MHz, Jeweller protocol
- **Pyronix Enforcer**: 868 MHz, two-way encrypted

## CC1101 Configuration for UK/EU

### 433.92 MHz Configuration (Primary)

```cpp
void configure_cc1101_uk_433mhz() {
    // UK/EU standard frequency
    cc1101_set_frequency(433920000);  // 433.92 MHz

    // ASK/OOK modulation (most common for CAME, PT2262, etc.)
    cc1101_set_modulation(CC1101_MOD_ASK_OOK);

    // Data rate for CAME (TE=320μs → ~3.125 kBaud)
    cc1101_set_data_rate(3125);

    // Bandwidth (200 kHz for ISM band)
    cc1101_set_bandwidth(CC1101_BW_200KHZ);

    // No deviation for OOK
    cc1101_set_deviation(0);

    // TX power (10 mW max in UK/EU - legal limit)
    cc1101_set_pa_table(0xC0);  // ~10 dBm (10 mW)

    // Receiver bandwidth filter
    cc1101_set_channel_filter(200);  // 200 kHz
}
```

### 868 MHz Configuration (Secondary)

```cpp
void configure_cc1101_uk_868mhz() {
    // EU sensor network frequency
    cc1101_set_frequency(868000000);  // 868.0 MHz

    // FSK modulation (common for sensor networks)
    cc1101_set_modulation(CC1101_MOD_2FSK);

    // Data rate for modern systems (~10 kBaud)
    cc1101_set_data_rate(10000);

    // Bandwidth
    cc1101_set_bandwidth(CC1101_BW_200KHZ);

    // Deviation for FSK
    cc1101_set_deviation(47);  // ±47 kHz deviation

    // TX power (10 mW max in UK/EU - legal limit)
    cc1101_set_pa_table(0xC0);  // ~10 dBm (10 mW)
}
```

## Protocol Detection for UK/EU Market

### TE-Based Protocol Detection

```cpp
typedef struct {
    const char* name;
    uint32_t te_min;  // Minimum TE (μs)
    uint32_t te_max;  // Maximum TE (μs)
    const char* origin;
    const char* usage;
} uk_eu_protocol_signature_t;

const uk_eu_protocol_signature_t uk_protocols[] = {
    {"CAME 12bit",     300,  340,  "Italy", "Garage doors, gates (UK #1)"},
    {"PT2262 24bit",   270,  420,  "Taiwan", "Generic remotes, alarms"},
    {"Holtek HT12X",   410,  450,  "Taiwan", "Budget remotes, Eastern Europe"},
    {"NICE FLO",       250,  350,  "Italy", "Garage doors (UK #2)"},
    {"BFT MITTO",      300,  400,  "Italy", "Premium gates, barriers"},
    {"Somfy RTS",      640,  680,  "France", "Window blinds, awnings"},
    {"KeeLoq",         400,  600,  "USA/EU", "Car keys (multiple manufacturers)"},
};

signal_info_t detect_uk_eu_protocol(uint8_t* raw_data, size_t len) {
    signal_info_t info;
    uint32_t te = measure_symbol_duration(raw_data, len);

    for (int i = 0; i < 7; i++) {
        if (te >= uk_protocols[i].te_min && te <= uk_protocols[i].te_max) {
            strcpy(info.protocol, uk_protocols[i].name);
            strcpy(info.origin, uk_protocols[i].origin);
            strcpy(info.usage, uk_protocols[i].usage);
            info.te = te;
            return info;
        }
    }

    strcpy(info.protocol, "Unknown UK/EU");
    return info;
}
```
