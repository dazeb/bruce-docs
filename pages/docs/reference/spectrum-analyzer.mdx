## Technical Implementation

### Data Collection (Background Task)

```cpp
// FreeRTOS task for RF scanning
void spectrum_analyzer_task(void *params) {
    while(1) {
        // Scan Sub-GHz bands (CC1101)
        for (int freq = 315; freq <= 915; freq += step) {
            cc1101_set_frequency(freq);
            int rssi = cc1101_read_rssi();
            spectrum_data_subghz[freq] = rssi;
        }

        // Scan 2.4GHz bands (nRF24 or WiFi)
        for (int channel = 0; channel <= 125; channel++) {
            nrf24_set_channel(channel);
            int rssi = nrf24_read_rssi();
            spectrum_data_24ghz[channel] = rssi;
        }

        vTaskDelay(pdMS_TO_TICKS(50)); // Update every 50ms
    }
}
```

### Display Update (Main Thread or Separate Task)

```cpp
void draw_spectrum_bars(int16_t *data, int data_size) {
    // PORTRAIT MODE: 240 width × 320 height
    int bar_width = 240 / data_size;
    int max_height = 200;  // Spectrum display area
    int baseline_y = 230;  // Y position of baseline

    for (int i = 0; i < data_size; i++) {
        // Convert RSSI to bar height (0-200 pixels)
        int height = map(data[i], -100, -20, 0, max_height);
        height = constrain(height, 0, max_height);

        // Color based on signal strength
        uint16_t color = get_signal_color(data[i]);

        // Draw bar from bottom up
        int x = i * bar_width;
        int y = baseline_y - height;  // Start from baseline
        tft.fillRect(x, y, bar_width - 2, height, color);
    }
}

uint16_t get_signal_color(int rssi) {
    if (rssi > -20) return COLOR_SIGNAL_STRONG;  // Red
    if (rssi > -40) return COLOR_SIGNAL_HIGH;    // Orange
    if (rssi > -60) return COLOR_SIGNAL_MEDIUM;  // Yellow
    if (rssi > -80) return COLOR_SIGNAL_LOW;     // Green
    return COLOR_SIGNAL_WEAK;                    // Blue
}
```

```cpp
void handle_spectrum_touch(int x, int y) {
    // PORTRAIT MODE: Check if touch is in spectrum area (y: 30-230)
    if (y < 30 || y > 230) return;  // Outside spectrum area

    // Touch on spectrum bar = lock onto that frequency

    // Visual feedback - highlight selected bar
    tft.drawRect(selected_channel * bar_width, 30, bar_width, 200, COLOR_LOCKED);

    Serial.printf("Locked on: %d MHz\n", locked_frequency);
}
```

## Performance Considerations

### Update Rate
- **Sweep mode**: Update every 50-100ms (10-20 FPS)
- **Locked mode**: Faster updates on single frequency (20-50ms)
- **Battery mode**: Slower updates (200-500ms) to save power

### Display Optimization
- Use partial screen updates (only redraw changed bars)
- Use DMA for faster SPI transfers to display
- Pre-calculate color lookup tables
- Consider using LVGL's chart widget (handles buffering)

### RF Module Speed
- **CC1101**: ~1-2ms per frequency hop + RSSI read
- **nRF24**: ~0.5ms per channel hop + carrier detect
- **ESP32 WiFi**: Native WiFi scan ~1-2 seconds (slower but comprehensive)
