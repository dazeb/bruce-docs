## Changelog Guidelines

### Format Requirements
1. **Timestamp**: ISO 8601 format `YYYY-MM-DD HH:MM:SS` for individual edits
2. **Session grouping**: Group related edits by day/session with subsections
3. **File tracking**: Always list affected files
4. **Impact assessment**: Note if changes affect:
   - Build configurations
   - Dependencies
   - Hardware requirements
   - Workflow changes
   - API or protocol changes

### Commit Discipline
- Update CHANGELOG.md BEFORE committing code changes
- Each git commit should reference corresponding changelog entries
- Use conventional commit messages aligned with changelog

### Review Protocol
- Weekly changelog review for consistency
- Monthly archival of old entries if needed
- Maintain running "Pending Changes" section
