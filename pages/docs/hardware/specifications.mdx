### Multi-Processor Design

```
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

#### Primary Controller: ESP32-S3

- **CPU**: Dual-core Xtensa LX7 @ 240MHz
- **RAM**: 512KB SRAM + 8MB PSRAM
- **Flash**: 16MB
- **WiFi**: 802.11b/g/n (2.4GHz)
- **Bluetooth**: BLE 5.0
- **USB**: Native USB OTG
- **Reason**: Most powerful ESP32, supports advanced features

#### Secondary WiFi/BLE: ESP32-C6

- **WiFi**: 802.11ax (WiFi 6) 2.4GHz
- **Bluetooth**: BLE 5.3 + 802.15.4 (Thread/Zigbee)
- **RISC-V**: 160MHz
- **Reason**: Latest protocols, Thread/Zigbee support, future-proof

#### GPIO Expansion: RP2040

- **Dual-core ARM Cortex-M0+** @ 133MHz
- **30 GPIO pins** (most programmable pins available)
- **12-bit ADC** (4 channels)
- **16 PWM channels**
- **PIO state machines** for custom protocols
- **Reason**: Massive GPIO count, flexible I/O, cheap

## Wireless Capabilities

### RF Transceivers

#### 1. CC1101 (Sub-GHz)

- **Frequency**: 300-348MHz, 387-464MHz, 779-928MHz
- **Modulation**: ASK, OOK, FSK, GFSK, MSK
- **Use Cases**:
  - Car key fobs (315/433/868/915MHz)
  - Weather stations
  - Garage door openers
  - ISM band research
  - Custom protocols

#### 2. NRF24L01+ (2.4GHz)

- **Frequency**: 2.4GHz ISM band
- **Protocols**: Enhanced ShockBurst
- **Use Cases**:
  - Wireless keyboards/mice attacks
  - Drones
  - RC toys
  - Custom 2.4GHz protocols

#### 3. RFM69HCW (ISM Bands)

- **Frequency**: 433/868/915MHz
- **Range**: Up to 500m
- **Use Cases**:
  - LoRa alternative
  - Long-range communication
  - Sensor networks

#### 4. SX1276 (LoRa)

- **Technology**: LoRa/LoRaWAN
- **Range**: 2-15km (depending on conditions)
- **Use Cases**:
  - LoRaWAN network research
  - Long-range IoT
  - Mesh networks

### RFID/NFC
