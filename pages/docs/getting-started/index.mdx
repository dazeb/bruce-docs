## 🎯 Choose Your Build

### Option 1: CYD Touchscreen Build (Recommended)
**Best for:** Standalone Bruce with professional UI

- ESP32-2432S028R (CYD) as primary controller
- 2.8" TFT touchscreen (240×320)
- Built-in SD card, RGB LED, speaker
- Connect RF modules to available GPIO
- **Guide:** [CYD Touchscreen Build](/docs/build-guides/touchscreen-build)

### Option 2: Waveshare Powerhouse
**Best for:** Maximum performance and capabilities

- Waveshare ESP32-S3 as primary (16MB+8MB)
- ESP32-C6 for WiFi 6 via I2C
- DollaTek 2.8" ILI9341 TFT Touch display
- All RF modules connected
- **Guide:** [Powerhouse Prototype](/docs/build-guides/powerhouse-prototype)

### Option 3: Multi-Board Architecture
**Best for:** Distributed processing and flexibility

- Separate boards for different functions
- Pico 2 W for GPIO expansion
- I2C/UART communication between boards
- **Guide:** [Multi-Board Build](/docs/build-guides/multi-board)
