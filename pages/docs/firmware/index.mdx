# Ultimate Flipper Zero Dev Board - Firmware Architecture

## Design Philosophy

1. **Modular**: Enable/disable features dynamically
2. **Conflict-Free**: Intelligent bus management to prevent SPI/I2C conflicts
3. **Power-Aware**: Selective module activation to conserve battery
4. **Professional**: Clean code, well-documented, testable
5. **Extensible**: Plugin architecture for community modules

## Multi-Processor Coordination

### ESP32-S3 (Primary Controller)

**Role**: Main coordinator and Flipper interface

**Responsibilities**:

- UART communication with Flipper Zero
- Command parsing and routing
- WiFi/BLE operations
- Data aggregation
- Power management
- Display updates
- File system operations
- Crypto operations (with ATECC608)

**Tasks**:

```c
xTaskCreate(flipper_comm_task,    "Flipper_UART", 4096, NULL, 5, NULL);
xTaskCreate(wifi_manager_task,    "WiFi_Mgr",     8192, NULL, 4, NULL);
xTaskCreate(display_task,         "Display",      2048, NULL, 3, NULL);
xTaskCreate(power_monitor_task,   "Power_Mon",    2048, NULL, 2, NULL);
xTaskCreate(file_manager_task,    "File_Mgr",     4096, NULL, 3, NULL);
```

### ESP32-C6 (WiFi 6 & IoT Protocols)

**Role**: Advanced wireless operations

**Responsibilities**:

- WiFi 6 (802.11ax) packet injection
- BLE 5.3 long-range scanning
- Thread/Zigbee protocol handling
- Offload intensive WiFi operations
- Mesh networking

**Communication with Primary**:

- **I2C Slave** mode (address 0x20)
- **Shared SPI** for bulk data transfers
- **IRQ line** for event notifications

**Tasks**:

```c
xTaskCreate(wifi6_scan_task,      "WiFi6_Scan",   8192, NULL, 5, NULL);
xTaskCreate(ble53_scan_task,      "BLE53_Scan",   4096, NULL, 4, NULL);
xTaskCreate(thread_protocol_task, "Thread",       4096, NULL, 3, NULL);
xTaskCreate(i2c_slave_task,       "I2C_Slave",    2048, NULL, 6, NULL);
```

### RP2040 (GPIO Expansion)

**Role**: GPIO flexibility and sensor interfacing

**Responsibilities**:

- Manage 30 GPIO pins
- ADC operations (12-bit, 4 channels)
- PWM generation (16 channels)
- PIO state machines for custom protocols
- Sensor data collection
- Fast GPIO toggling

**Communication with Primary**:

- **SPI Slave** mode for high-speed data
- **I2C Slave** mode for commands (address 0x21)

**Cores**:

- **Core 0**: Main logic, communication
- **Core 1**: Real-time GPIO operations, PIO

## Bus Management (Critical!)

### Problem: The BFFB Issue

BFFB had SPI conflicts causing crashes. We solve this with intelligent bus management.

### Our Solution: Multi-Bus Architecture

#### SPI Bus Assignment

```
SPI1 (Primary) - ESP32-S3 HSPI
├── CC1101 #1 (315MHz)   - CS: GPIO5
├── CC1101 #2 (433MHz)   - CS: GPIO15
└── CC1101 #3 (915MHz)   - CS: GPIO13

SPI2 (Secondary) - ESP32-S3 VSPI
├── nRF24L01+ PA/LNA     - CS: GPIO25
├── SX1276 (LoRa)        - CS: GPIO26
├── W25Q512 (Flash)      - CS: GPIO27
└── PN532 (NFC)          - CS: GPIO32 (alt: I2C mode)

SPI3 (Dedicated) - ESP32-S3 SPI3
└── MicroSD Card         - CS: GPIO33
    (Or use SDIO 4-bit mode for faster speeds)

RP2040 SPI (Isolated)
└── Communication with ESP32-S3
```

#### I2C Bus Assignment

```
I2C0 (Primary) - ESP32-S3
├── ESP32-C6             - Address: 0x20
├── RP2040               - Address: 0x21
├── OLED SSD1306         - Address: 0x3C
├── BME680               - Address: 0x76
├── MPU9250              - Address: 0x68
├── ATECC608A            - Address: 0x60
├── MAX17048 (Fuel Gauge)- Address: 0x36
└── PN532 (alt)          - Address: 0x24

I2C1 (Expansion) - RP2040
├── Qwiic Connector 1    - User modules
└── Qwiic Connector 2    - User modules

I2C2 (Sensors) - ESP32-C6
└── Future expansion
```

#### UART Assignment

```
UART0 (ESP32-S3)
└── Flipper Zero         - RX: GPIO16, TX: GPIO17

UART1 (ESP32-S3)
└── GPS NEO-M8N          - RX: GPIO18, TX: GPIO19

UART2 (ESP32-S3)
└── Debug console        - USB CDC (native USB)

UART0 (RP2040)
└── Debug/expansion
```

### Bus Arbitration

```c
// SPI Bus Manager
typedef struct {
    SemaphoreHandle_t mutex;
    spi_host_device_t host;
    uint32_t freq_hz;
    bool in_use;
} spi_bus_t;

spi_bus_t spi_buses[3] = {
    { .host = SPI1_HOST, .freq_hz = 8000000 },  // CC1101s
    { .host = SPI2_HOST, .freq_hz = 10000000 }, // nRF24, LoRa
    { .host = SPI3_HOST, .freq_hz = 20000000 }  // SD card
};

esp_err_t acquire_spi_bus(spi_bus_t* bus, TickType_t timeout) {
    if (xSemaphoreTake(bus->mutex, timeout) == pdTRUE) {
        bus->in_use = true;
        return ESP_OK;
    }
    return ESP_ERR_TIMEOUT;
}

void release_spi_bus(spi_bus_t* bus) {
    bus->in_use = false;
    xSemaphoreGive(bus->mutex);
}
```

### Battery Monitoring

```c
typedef struct {
    float voltage;           // Battery voltage
    float current_ma;        // Current draw
    uint8_t soc_percent;    // State of charge
    bool charging;
    uint32_t time_remaining_min;
} battery_status_t;

void battery_monitor_task(void* pvParameters) {
    battery_status_t status;

    while(1) {
        // Read from MAX17048 fuel gauge via I2C
        max17048_read_soc(&status.soc_percent);
        max17048_read_vcell(&status.voltage);

        // Calculate current from BQ25895
        bq25895_read_current(&status.current_ma);
        bq25895_get_charging_status(&status.charging);

        // Estimate remaining time
        if (status.current_ma > 0 && !status.charging) {
            uint32_t capacity_mah = 3000; // 18650 typical
            uint32_t remaining_mah = (capacity_mah * status.soc_percent) / 100;
            status.time_remaining_min = (remaining_mah * 60) / status.current_ma;
        }

        // Send to display task
        xQueueSend(battery_status_queue, &status, 0);

        vTaskDelay(pdMS_TO_TICKS(5000)); // Update every 5 seconds
    }
}
```

## Plugin System

### Plugin Interface

```c
typedef struct plugin_t {
    const char* name;
    const char* version;
    const char* author;

    // Lifecycle callbacks
    esp_err_t (*init)(void);
    esp_err_t (*start)(void);
    esp_err_t (*stop)(void);
    esp_err_t (*deinit)(void);

    // Dependencies
    const char** required_modules;  // ["CC1101_1", "GPS", NULL]
    uint32_t min_free_heap;         // Minimum heap required
    power_state_t min_power_state;

    // Command handling
    esp_err_t (*handle_command)(const char* cmd, const char* args, char* response, size_t max_len);

    // Event handling
    void (*on_event)(const char* event, void* data);

    TaskHandle_t task_handle;
    bool loaded;
    bool running;
} plugin_t;
```

### Example Plugin: WiFi Scanner

```c
plugin_t wifi_scanner_plugin = {
    .name = "WiFi Scanner",
    .version = "1.0.0",
    .author = "Community",
    .init = wifi_scanner_init,
    .start = wifi_scanner_start,
    .stop = wifi_scanner_stop,
    .deinit = wifi_scanner_deinit,
    .required_modules = (const char*[]){"WiFi", NULL},
    .min_free_heap = 64 * 1024,
    .min_power_state = POWER_STATE_WIFI_ONLY,
    .handle_command = wifi_scanner_command,
    .on_event = wifi_scanner_event,
};

esp_err_t wifi_scanner_init(void) {
    ESP_LOGI(TAG, "WiFi Scanner plugin initializing...");
    // Initialize WiFi in promiscuous mode
    wifi_init_config_t cfg = WIFI_INIT_CONFIG_DEFAULT();
    ESP_ERROR_CHECK(esp_wifi_init(&cfg));
    ESP_ERROR_CHECK(esp_wifi_set_mode(WIFI_MODE_STA));
    ESP_ERROR_CHECK(esp_wifi_start());
    return ESP_OK;
}

esp_err_t wifi_scanner_start(void) {
    xTaskCreate(wifi_scan_task, "WiFi_Scan", 8192, NULL, 4, &wifi_scanner_plugin.task_handle);
    wifi_scanner_plugin.running = true;
    return ESP_OK;
}

esp_err_t wifi_scanner_command(const char* cmd, const char* args, char* response, size_t max_len) {
    if (strcmp(cmd, "START_SCAN") == 0) {
        wifi_start_scan();
        snprintf(response, max_len, "OK: Scan started");
        return ESP_OK;
    }
    return ESP_ERR_NOT_SUPPORTED;
}
```

### Plugin Manager

```c
#define MAX_PLUGINS 32
plugin_t* loaded_plugins[MAX_PLUGINS];
uint8_t plugin_count = 0;

esp_err_t plugin_manager_load(plugin_t* plugin) {
    // Check dependencies
    for (const char** dep = plugin->required_modules; *dep != NULL; dep++) {
        if (!is_module_available(*dep)) {
            ESP_LOGE(TAG, "Plugin %s requires %s", plugin->name, *dep);
            return ESP_ERR_NOT_FOUND;
        }
    }

    // Check heap
    if (esp_get_free_heap_size() < plugin->min_free_heap) {
        ESP_LOGE(TAG, "Not enough heap for %s", plugin->name);
        return ESP_ERR_NO_MEM;
    }

    // Initialize
    esp_err_t ret = plugin->init();
    if (ret != ESP_OK) {
        return ret;
    }

    loaded_plugins[plugin_count++] = plugin;
    plugin->loaded = true;

    ESP_LOGI(TAG, "Loaded plugin: %s v%s", plugin->name, plugin->version);
    return ESP_OK;
}

esp_err_t plugin_manager_start(const char* plugin_name) {
    plugin_t* plugin = find_plugin(plugin_name);
    if (plugin && plugin->loaded) {
        return plugin->start();
    }
    return ESP_ERR_NOT_FOUND;
}
```

### Extended Protocol (JSON-RPC over UART)

```json
{
  "jsonrpc": "2.0",
  "method": "plugin.execute",
  "params": {
    "plugin": "wifi_scanner",
    "command": "START_SCAN",
    "args": {
      "channel": 6,
      "duration": 30
    }
  },
  "id": 1
}
```

**Response**:

```json
{
  "jsonrpc": "2.0",
  "result": {
    "status": "scanning",
    "networks": 12,
    "filename": "/sd/scan_001.pcap"
  },
  "id": 1
}
```

### Binary Protocol (High-Speed)

For bulk data (packet captures, GPS logs):

```
┌────────┬────────┬────────┬────────┬──────────┬──────────┐
│ SYNC   │ TYPE   │ LENGTH │ SEQ_NUM│  DATA    │ CHECKSUM │
├────────┼────────┼────────┼────────┼──────────┼──────────┤
│ 0xAABB │ 1 byte │ 2 bytes│ 2 bytes│ N bytes  │ 2 bytes  │
└────────┴────────┴────────┴────────┴──────────┴──────────┘
```

**Types**:

- `0x01`: Command
- `0x02`: Response
- `0x03`: Event/notification
- `0x04`: Stream data (packets, GPS, etc.)
- `0x05`: File transfer

## OTA (Over-The-Air) Updates

### Update Sources

1. **WiFi** - Download from update server
2. **USB** - Mass storage mode
3. **SD Card** - Load from /firmware/
4. **Flipper Zero** - Transfer via UART

### Update Process

```c
void ota_update_task(void* pvParameters) {
    esp_http_client_config_t config = {
        .url = "https://updates.example.com/firmware.bin",
        .cert_pem = server_cert,
    };

    esp_err_t ret = esp_https_ota(&config);

    if (ret == ESP_OK) {
        ESP_LOGI(TAG, "OTA successful, rebooting...");
        vTaskDelay(pdMS_TO_TICKS(1000));
        esp_restart();
    } else {
        ESP_LOGE(TAG, "OTA failed: %s", esp_err_to_name(ret));
    }
}
```

### Multi-MCU Coordination

```c
void update_all_mcus(void) {
    // 1. Update ESP32-S3 (primary)
    update_esp32s3();

    // 2. Signal ESP32-C6 to update
    i2c_write_command(ESP32_C6_ADDR, CMD_UPDATE_FIRMWARE);

    // 3. Signal RP2040 to enter bootloader
    gpio_set_level(RP2040_BOOTSEL_PIN, 1);
    gpio_set_level(RP2040_RESET_PIN, 0);
    vTaskDelay(pdMS_TO_TICKS(100));
    gpio_set_level(RP2040_RESET_PIN, 1);

    // RP2040 appears as USB mass storage, upload .uf2
}
```

### Using ATECC608 Secure Element

```c
void crypto_init(void) {
    // Initialize I2C to ATECC608
    atca_cfg_t cfg = {
        .iface_type = ATCA_I2C_IFACE,
        .atcai2c.slave_address = 0x60,
        .atcai2c.bus = 0,
        .atcai2c.baud = 100000,
    };

    atcab_init(&cfg);

    // Generate device certificate if needed
    uint8_t public_key[64];
    atcab_genkey(0, public_key);
}

esp_err_t sign_data(const uint8_t* data, size_t len, uint8_t* signature) {
    uint8_t digest[32];

    // Hash data
    mbedtls_sha256(data, len, digest, 0);

    // Sign with ATECC608 private key
    return atcab_sign(0, digest, signature);
}
```
