## 📋 Hardware Specifications

**Your Build: Waveshare ESP32-S3 + DollaTek ILI9341 Display Module**

### Primary Controller: Waveshare ESP32-S3-WROOM-1

- **MCU:** ESP32-S3 (Dual-core Xtensa LX7, 240MHz)
- **Flash:** 16MB
- **PSRAM:** 8MB
- **WiFi:** 2.4GHz 802.11 b/g/n
- **Bluetooth:** BLE 5.0
- **USB:** Type-C with CP2102N USB-UART bridge
- **GPIO:** All pins broken out to headers
- **Power:** 3.3V logic, 5V USB input

### Display Module: DollaTek 2.8" ILI9341 TFT Touch

- **Display:** 2.8" TFT LCD, 240×320 pixels, 262K/65K colors
- **Display Driver:** ILI9341 (industry standard)
- **Touch Controller:** XPT2046 (resistive touch)
- **MicroSD:** Built-in card slot on module
- **Interface:** SPI (4-wire for display + touch)
- **Voltage:** 5V or 3.3V compatible (onboard regulator)
- **Form Factor:** Breadboard-friendly with pin headers

### Pin Configuration

**DollaTek ILI9341 Display SPI Pins:**

```
Display Pin → ESP32-S3 Pin
VCC        → 5V or 3.3V (module has voltage regulator)
GND        → GND
CS         → GPIO 10
RESET      → GPIO 9 (or 3.3V for always-on)
DC/RS      → GPIO 8
SDI/MOSI   → GPIO 11 (SPI MOSI)
SCK        → GPIO 12 (SPI SCK)
LED        → 3.3V (backlight always on) or GPIO for PWM control
SDO/MISO   → GPIO 13 (SPI MISO, optional for reading)
```

**XPT2046 Touch Controller Pins:**

```
Touch Pin  → ESP32-S3 Pin
T_CLK      → GPIO 12 (shared SPI SCK)
T_CS       → GPIO 14
T_DIN      → GPIO 11 (shared SPI MOSI)
T_DO       → GPIO 13 (shared SPI MISO)
T_IRQ      → GPIO 15 (optional interrupt)
```

**⚠️ NOTE:** Touch controller shares SPI bus with display but has separate CS pin.

**SD Card on Display Module (Optional):**

```
SD Pin     → ESP32-S3 Pin
SD_CS      → GPIO 16
SD_MOSI    → GPIO 11 (shared SPI)
SD_MISO    → GPIO 13 (shared SPI)
SD_SCK     → GPIO 12 (shared SPI)
```

**Available GPIO for RF Modules:**

```
Free GPIOs on Waveshare ESP32-S3:
GPIO 1-7, 17-21, 35-48 (many options!)

Recommended for RF:
- GPIO 5, 6, 7 for CC1101 (separate SPI + CS + GDO0)
- GPIO 17, 18 for nRF24 (CE + CS)
- GPIO 19, 20 for I2C (ESP32-C6)
```

## 🔧 Arduino IDE Setup

### Step 1: Install ESP32 Board Support

1. Open Arduino IDE
2. Go to **File → Preferences**
3. Add to "Additional Board Manager URLs":

   ```
   https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
   ```
4. Go to **Tools → Board → Boards Manager**
5. Search "ESP32" and install **"esp32 by Espressif Systems"** (v3.0.0 or later)

### Step 2: Select Board

1. Go to **Tools → Board → esp32**
2. Select **"ESP32S3 Dev Module"**
3. Configure board settings:

   ```
   Board: "ESP32S3 Dev Module"
   Upload Speed: "921600"
   USB Mode: "Hardware CDC and JTAG"
   USB CDC On Boot: "Enabled"
   USB Firmware MSC On Boot: "Disabled"
   USB DFU On Boot: "Disabled"
   Upload Mode: "UART0 / Hardware CDC"
   CPU Frequency: "240MHz (WiFi)"
   Flash Mode: "QIO 80MHz"
   Flash Size: "16MB (128Mb)"
   Partition Scheme: "16M Flash (3MB APP/9.9MB FATFS)"
   Core Debug Level: "None"
   PSRAM: "OPI PSRAM"
   Arduino Runs On: "Core 1"
   Events Run On: "Core 1"
   ```
4. Select your COM port: **Tools → Port → COMx**

### Step 3: Install Required Libraries

Open **Tools → Manage Libraries** and install:

1. **TFT_eSPI** by Bodmer (v2.5.43 or later)
2. **XPT2046_Touchscreen** by Paul Stoffregen
3. **RadioLib** (for CC1101, LoRa, nRF24) - optional for RF
4. **ArduinoJson** (for configuration files) - optional

## ⚙️ Configure TFT_eSPI Library

### CRITICAL: Custom User_Setup.h Configuration

1. Find TFT_eSPI library folder:

   - Windows: `Documents\Arduino\libraries\TFT_eSPI`
   - Mac: `~/Documents/Arduino/libraries/TFT_eSPI`
   - Linux: `~/Arduino/libraries/TFT_eSPI`

2. **BACKUP the original `User_Setup.h` file first!**

3. Open `User_Setup.h` in a text editor

4. **Comment out ALL default drivers and pins**, then add this configuration:

```cpp
// ═══════════════════════════════════════════════════════════════
//   BRUCE - Waveshare ESP32-S3 + DollaTek ILI9341 Configuration
// ═══════════════════════════════════════════════════════════════

// Driver Selection
#define ILI9341_DRIVER      // Use ILI9341 driver for DollaTek display

// ESP32-S3 Custom Display Pins
#define TFT_MISO 13  // SPI MISO
#define TFT_MOSI 11  // SPI MOSI
#define TFT_SCLK 12  // SPI SCK
#define TFT_CS   10  // Chip select
#define TFT_DC    8  // Data/Command
#define TFT_RST   9  // Reset (or connect to 3.3V)
// #define TFT_BL   -1  // Backlight (connect to 3.3V or use GPIO for PWM)

// Color correction (adjust if colors look wrong)
// #define TFT_INVERSION_ON
// #define TFT_RGB_ORDER TFT_BGR  // Uncomment if red/blue swapped

// SPI Frequency
#define SPI_FREQUENCY  40000000  // 40MHz for display (fast!)
#define SPI_READ_FREQUENCY  20000000
#define SPI_TOUCH_FREQUENCY  2500000  // 2.5MHz for touch

// Font Packages
#define LOAD_GLCD   // Font 1. Original Adafruit 8 pixel font
#define LOAD_FONT2  // Font 2. Small 16 pixel high font
#define LOAD_FONT4  // Font 4. Medium 26 pixel high font
#define LOAD_FONT6  // Font 6. Large 48 pixel font
#define LOAD_FONT7  // Font 7. 7 segment 48 pixel font
#define LOAD_FONT8  // Font 8. Large 75 pixel font
#define LOAD_GFXFF  // FreeFonts

#define SMOOTH_FONT  // Enable anti-aliased fonts

// ═══════════════════════════════════════════════════════════════
```

5. Save and close `User_Setup.h`

**⚠️ IMPORTANT:** If you get compilation errors, make sure you commented out ALL other driver and pin definitions in User_Setup.h!

## 🎨 Bruce Touchscreen Test Code

### Basic Display Test

```cpp
#include <TFT_eSPI.h>

TFT_eSPI tft = TFT_eSPI();

void setup() {
    Serial.begin(115200);
    delay(1000);
    Serial.println("🦈 BRUCE: Display test starting...");

    // Initialize display
    tft.init();
    tft.setRotation(0);       // Portrait mode (0 or 2)
    tft.fillScreen(TFT_BLACK);

    // Display Bruce bootscreen
    drawBruceBootscreen();

    Serial.println("🦈 BRUCE: Bootscreen displayed!");
}

void loop() {
    // Test color pattern
    delay(3000);
    testColors();
}

void drawBruceBootscreen() {
    tft.fillScreen(TFT_BLACK);

    // Draw shark ASCII art
    tft.setTextColor(TFT_CYAN, TFT_BLACK);
    tft.setTextSize(2);
    tft.setCursor(90, 50);
    tft.println("/>");
    tft.setCursor(70, 70);
    tft.println("//");
    tft.setCursor(50, 90);
    tft.println("//");
    tft.setCursor(30, 110);
    tft.println("//___");

    // Draw title
    tft.setTextColor(TFT_WHITE, TFT_BLACK);
    tft.setTextSize(4);
    tft.setCursor(40, 150);
    tft.println("BRUCE");

    // Draw subtitle
    tft.setTextSize(2);
    tft.setCursor(30, 195);
    tft.println("Big Brother");

    // Draw status
    tft.setTextColor(TFT_GREEN, TFT_BLACK);
    tft.setCursor(20, 230);
    tft.println("Mode: ACTIVE");

    // Draw tagline
    tft.setTextColor(TFT_CYAN, TFT_BLACK);
    tft.setTextSize(1);
    tft.setCursor(20, 270);
    tft.println("Step aside, kid.");
    tft.setCursor(20, 285);
    tft.println("I've got this.");
}

void testColors() {
    const uint16_t colors[] = {TFT_RED, TFT_GREEN, TFT_BLUE,
                               TFT_CYAN, TFT_MAGENTA, TFT_YELLOW};
    const char* names[] = {"RED", "GREEN", "BLUE",
                          "CYAN", "MAGENTA", "YELLOW"};

    for (int i = 0; i < 6; i++) {
        tft.fillScreen(colors[i]);
        tft.setTextColor(TFT_BLACK, colors[i]);
        tft.setTextSize(3);
        tft.setCursor(60, 140);
        tft.println(names[i]);
        delay(1000);
    }

    drawBruceBootscreen();  // Return to bootscreen
}
```

**Expected Result:** Display shows Bruce bootscreen, then cycles through colors.

**⚠️ Troubleshooting:**
- If display is blank: Check wiring, especially CS and DC pins
- If colors are inverted: Uncomment `TFT_INVERSION_ON` in User_Setup.h
- If red/blue swapped: Uncomment `TFT_RGB_ORDER TFT_BGR` in User_Setup.h

### Touch Test with Calibration

```cpp
#include <TFT_eSPI.h>
#include <XPT2046_Touchscreen.h>

TFT_eSPI tft = TFT_eSPI();

// Touch pins
#define TOUCH_CS 14
#define TOUCH_IRQ 15
XPT2046_Touchscreen touch(TOUCH_CS, TOUCH_IRQ);

// Calibration values (adjust after testing raw values)
#define TOUCH_MIN_X 200
#define TOUCH_MAX_X 3700
#define TOUCH_MIN_Y 240
#define TOUCH_MAX_Y 3800

void setup() {
    Serial.begin(115200);
    delay(1000);
    Serial.println("🦈 BRUCE: Touch test starting...");

    // Initialize display
    tft.init();
    tft.setRotation(0);  // Portrait
    tft.fillScreen(TFT_BLACK);

    // Initialize touch
    touch.begin();
    touch.setRotation(0);

    // Draw instructions
    tft.setTextColor(TFT_WHITE, TFT_BLACK);
    tft.setTextSize(2);
    tft.setCursor(20, 20);
    tft.println("BRUCE TOUCH TEST");

    tft.setTextSize(1);
    tft.setCursor(20, 60);
    tft.println("Touch anywhere to test");
    tft.setCursor(20, 80);
    tft.println("Check Serial Monitor");
    tft.setCursor(20, 100);
    tft.println("for raw values");

    Serial.println("Touch screen to see coordinates");
    Serial.println("Format: Raw: X=#### Y=#### | Mapped: X=### Y=###");
}

void loop() {
    if (touch.touched()) {
        TS_Point p = touch.getPoint();

        // Map touch coordinates to screen (240x320)
        int x = map(p.x, TOUCH_MIN_X, TOUCH_MAX_X, 0, 240);
        int y = map(p.y, TOUCH_MIN_Y, TOUCH_MAX_Y, 0, 320);

        // Constrain to screen bounds
        x = constrain(x, 0, 239);
        y = constrain(y, 0, 319);

        // Print raw and mapped values
        Serial.printf("Raw: X=%d Y=%d Z=%d | ", p.x, p.y, p.z);
        Serial.printf("Mapped: X=%d Y=%d\n", x, y);

        // Draw touch point
        tft.fillCircle(x, y, 3, TFT_CYAN);

        // Show coordinates on screen
        tft.fillRect(0, 280, 240, 40, TFT_BLACK);
        tft.setTextColor(TFT_GREEN, TFT_BLACK);
        tft.setTextSize(2);
        tft.setCursor(10, 285);
        tft.printf("X:%3d Y:%3d", x, y);

        delay(50);  // Debounce
    }
}
```

**Calibration Process:**
1. Upload this code
2. Touch the four corners of the screen
3. Note the raw X and Y values in Serial Monitor
4. Update TOUCH_MIN_X, TOUCH_MAX_X, TOUCH_MIN_Y, TOUCH_MAX_Y with your values
5. Re-upload and test - touch points should now be accurate
