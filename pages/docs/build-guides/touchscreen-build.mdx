### Why This Architecture Dominates

**1. ESP32-S3 Brain + Separate Display = Ultimate Power**
- ESP32-S3: 240MHz dual-core powerhouse with 8MB PSRAM
- DollaTek ILI9341: Professional touchscreen (breadboard-friendly)
- Modular design: Easy to prototype and debug
- Display has built-in SD card slot for data logging

**2. ESP32-C6 as WiFi 6 Co-Processor = Future-Proof**
- Offloads WiFi 6 operations
- BLE 5.3 long-range scanning
- Thread/Zigbee IoT protocols
- Keeps primary ESP32-S3 focused on RF and GUI

**3. Dedicated LoRa Board = Standalone Capability**
- DollaTek ESP32 runs Meshtastic independently
- Can mesh with other LoRa nodes
- Built-in display for field use
- WiFi links back to main ESP32-S3 when in range

**4. Modular RF = No Bus Conflicts**
- Each RF module on separate SPI bus
- Breadboard-friendly for prototyping
- Hot-swappable configurations
- Zero crashes (Bruce doesn't crash)

## 🔧 Pin Assignments: Waveshare ESP32-S3 + DollaTek ILI9341

### DollaTek ILI9341 Display Connection (via SPI)
```
Display Pin → ESP32-S3 Pin
VCC        → 5V or 3.3V (module has voltage regulator)
GND        → GND
CS         → GPIO 10
RESET      → GPIO 9 (or 3.3V for always-on)
DC/RS      → GPIO 8
SDI/MOSI   → GPIO 11 (SPI MOSI)
SCK        → GPIO 12 (SPI SCK)
LED        → 3.3V (backlight always on) or GPIO for PWM control
SDO/MISO   → GPIO 13 (SPI MISO, if reading from display)
```

### DollaTek XPT2046 Touch Controller (via SPI)
```
Touch Pin  → ESP32-S3 Pin
T_CLK      → GPIO 12 (shared SPI SCK)
T_CS       → GPIO 14
T_DIN      → GPIO 11 (shared SPI MOSI)
T_DO       → GPIO 13 (shared SPI MISO)
T_IRQ      → GPIO 15 (optional interrupt)
```

### SD Card on Display Module (Optional)
```
SD Pin     → ESP32-S3 Pin
SD_CS      → GPIO 16
SD_MOSI    → GPIO 11 (shared SPI)
SD_MISO    → GPIO 13 (shared SPI)
SD_SCK     → GPIO 12 (shared SPI)
```

### Available GPIO for RF Modules
```
Available pins on Waveshare ESP32-S3:
GPIO 1-7, 17-21, 35-48 (many options!)
Recommended for RF:
- GPIO 5, 6, 7 for CC1101 (SPI + CS + GDO0)
- GPIO 17, 18 for nRF24 (CE + CS)
- GPIO 19, 20 for I2C (ESP32-C6)
```

### Recommended RF Module Pinout

**CC1101 (SPI) - Sub-GHz:**
```
CC1101_MOSI = 5   // SPI MOSI (can share with nRF24)
CC1101_MISO = 6   // SPI MISO (can share with nRF24)
CC1101_SCK  = 7   // SPI SCK  (can share with nRF24)
CC1101_CS   = 4   // Chip Select (unique)
CC1101_GDO0 = 3   // Interrupt pin
CC1101_GDO2 = 2   // Optional
```

**nRF24L01+ PA/LNA (SPI) - 2.4GHz:**
```
NRF24_MOSI = 5   // SPI MOSI (shared with CC1101)
NRF24_MISO = 6   // SPI MISO (shared with CC1101)
NRF24_SCK  = 7   // SPI SCK  (shared with CC1101)
NRF24_CS   = 18  // Chip Select (unique)
NRF24_CE   = 17  // Chip Enable
```

**ESP32-C6 (I2C) - WiFi 6 Co-Processor:**
```
I2C_SDA = 19
I2C_SCL = 20
C6_ADDR = 0x20  // I2C slave address
```

**Flipper Zero (UART) - Optional:**
```
UART_TX = 43  // ESP32-S3 TX → Flipper RX
UART_RX = 44  // ESP32-S3 RX → Flipper TX
UART_BAUD = 115200
```

### Phase 4: Add ESP32-C6 (WiFi 6 Co-Processor)

**Hardware:**
- Waveshare ESP32-C6 (you have it!)
- I2C connection to touchscreen ESP32

**Wiring:**
```
Touchscreen ESP32  →  ESP32-C6
    GPIO 27 (SDA)  →  GPIO 6 (SDA)
    GPIO 26 (SCL)  →  GPIO 7 (SCL)
    GND            →  GND
    3.3V           →  3.3V
```

**ESP32-C6 Firmware (I2C Slave):**
```cpp
#include <Wire.h>

#define I2C_SLAVE_ADDR 0x20

void setup() {
    Wire.begin(I2C_SLAVE_ADDR);
    Wire.onReceive(receiveEvent);
    Wire.onRequest(requestEvent);

    // Initialize WiFi 6
    WiFi.mode(WIFI_STA);
}

void receiveEvent(int bytes) {
    // Commands from primary ESP32
    uint8_t cmd = Wire.read();

    switch(cmd) {
        case CMD_WIFI_SCAN:
            scan_wifi6_networks();
            break;
        case CMD_BLE_SCAN:
            scan_ble53_devices();
            break;
    }
}
```
