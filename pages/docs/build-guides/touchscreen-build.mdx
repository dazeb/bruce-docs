### Why This Architecture Dominates

**1. Touchscreen ESP32 as Primary = Superior UX**
- Rich GUI with icons, buttons, graphs
- Real-time spectrum analyzer visualization
- Touch controls (no button mashing)
- Status at a glance

**2. ESP32-C6 as WiFi 6 Co-Processor = Future-Proof**
- Offloads WiFi 6 operations
- BLE 5.3 long-range scanning
- Thread/Zigbee IoT protocols
- Keeps primary ESP32 focused on GUI

**3. Dedicated LoRa Board = Standalone Capability**
- DollaTek ESP32 runs Meshtastic independently
- Can mesh with other LoRa nodes
- Built-in display for field use
- WiFi links back to main touchscreen when in range

**4. Modular RF = No Bus Conflicts**
- Each RF module on separate SPI bus or board
- Hot-swappable configurations
- Zero crashes (Bruce doesn't crash)

## 🔧 Pin Assignments: ESP32-2432S028R

### Built-in TFT Display (Already Connected!)
```
TFT_MISO = 12
TFT_MOSI = 13
TFT_SCLK = 14
TFT_CS   = 15
TFT_DC   = 2
TFT_RST  = -1  // Not used
TFT_BL   = 21  // Backlight
```

### Touch Controller (Already Connected!)
```
TOUCH_CS = 33
TOUCH_IRQ = 36
```

### Available GPIO for RF Modules
```
Available pins on ESP32-2432S028R:
GPIO 0, 4, 16, 17, 22, 23, 25, 26, 27, 32, 34, 35
```

### Recommended RF Module Pinout

**CC1101 (SPI) - Sub-GHz:**
```
CC1101_MOSI = 23  // SPI MOSI (shared with nRF24)
CC1101_MISO = 19  // SPI MISO (shared with nRF24)
CC1101_SCK  = 18  // SPI SCK  (shared with nRF24)
CC1101_CS   = 5   // Chip Select (unique)
CC1101_GDO0 = 4   // Interrupt pin
CC1101_GDO2 = 16  // Optional
```

**nRF24L01+ PA/LNA (SPI) - 2.4GHz:**
```
NRF24_MOSI = 23  // SPI MOSI (shared with CC1101)
NRF24_MISO = 19  // SPI MISO (shared with CC1101)
NRF24_SCK  = 18  // SPI SCK  (shared with CC1101)
NRF24_CS   = 17  // Chip Select (unique)
NRF24_CE   = 22  // Chip Enable
```

**ESP32-C6 (I2C) - WiFi 6 Co-Processor:**
```
I2C_SDA = 27
I2C_SCL = 26
C6_ADDR = 0x20  // I2C slave address
```

**Flipper Zero (UART) - Optional:**
```
UART_TX = 1   // ESP32 TX → Flipper RX
UART_RX = 3   // ESP32 RX → Flipper TX
UART_BAUD = 115200
```

### Phase 4: Add ESP32-C6 (WiFi 6 Co-Processor)

**Hardware:**
- Waveshare ESP32-C6 (you have it!)
- I2C connection to touchscreen ESP32

**Wiring:**
```
Touchscreen ESP32  →  ESP32-C6
    GPIO 27 (SDA)  →  GPIO 6 (SDA)
    GPIO 26 (SCL)  →  GPIO 7 (SCL)
    GND            →  GND
    3.3V           →  3.3V
```

**ESP32-C6 Firmware (I2C Slave):**
```cpp
#include <Wire.h>

#define I2C_SLAVE_ADDR 0x20

void setup() {
    Wire.begin(I2C_SLAVE_ADDR);
    Wire.onReceive(receiveEvent);
    Wire.onRequest(requestEvent);

    // Initialize WiFi 6
    WiFi.mode(WIFI_STA);
}

void receiveEvent(int bytes) {
    // Commands from primary ESP32
    uint8_t cmd = Wire.read();

    switch(cmd) {
        case CMD_WIFI_SCAN:
            scan_wifi6_networks();
            break;
        case CMD_BLE_SCAN:
            scan_ble53_devices();
            break;
    }
}
```

**Time:** 3-4 hours
**Cost:** £0 (you have it!)
**Result:** Bruce has WiFi 6 + BLE 5.3!
