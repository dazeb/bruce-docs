## 🔌 Complete Wiring Diagram

### ESP32-S3 to Power Rails

```
ESP32-S3 Power Distribution:
┌─────────────────────────────────────┐
│  Waveshare ESP32-S3-WROOM-1         │
│                                     │
│  3V3 Pin ───────────► [+] Red Rail  │  Supply 3.3V to all components
│  GND Pin ───────────► [-] Black Rail│  Common ground
│                                     │
│  (Multiple GND pins available)      │
└─────────────────────────────────────┘

CRITICAL: ESP32-S3 operates at 3.3V ONLY!
⚠️ Never connect 5V to GPIO pins - instant destruction!
```

### I2C Pull-up Resistors (MUST DO FIRST!)

```
I2C Pull-up Configuration (REQUIRED for reliable operation):

         3.3V (+) Rail
            │
            ├─── [4.7kΩ] ───┬─── SDA (GPIO21)
            │                │
            └─── [4.7kΩ] ───┴─── SCL (GPIO22)

Why This Is Critical:
- I2C is an open-drain bus and REQUIRES pull-ups
- Without pull-ups: Communication will fail or be unreliable
- 4.7kΩ is ideal for multiple devices at moderate speeds
- 10kΩ works but may cause issues with multiple devices
- 3.3kΩ also works but draws more current

Physical Placement:
- Place resistors near the ESP32-S3
- Keep leads short to minimize noise
- Verify connections with multimeter (should read ~4.7kΩ)
```

### SPI3 Bus - DollaTek 2.8" ILI9341 Display

```
ESP32-S3 to DollaTek ILI9341 TFT Display (SPI3 Bus):

DollaTek Display Pin    ESP32-S3 GPIO    Notes
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
VCC                     3.3V (+) Rail    Power (3.3V or 5V, module has regulator)
GND                     GND (-) Rail     Ground
CS  (Chip Select)       GPIO15           Active LOW, dedicates display
RESET                   GPIO4            Display reset (active LOW)
DC  (Data/Command)      GPIO2            LOW=Command, HIGH=Data
MOSI (SDI/SDA)          GPIO23           Master Out Slave In (SPI data to display)
SCK  (Clock)            GPIO18           SPI clock signal
LED (Backlight)         3.3V (+) Rail    Backlight power (or PWM via GPIO for dimming)
MISO (SDO)              GPIO19           Master In Slave Out (optional for SD card)

Touch Controller (XPT2046):
T_CLK                   GPIO18           Shared with display SPI clock
T_CS                    GPIO14           Touch controller chip select
T_DIN                   GPIO23           Shared with display MOSI
T_DO                    GPIO19           Shared with display MISO
T_IRQ                   GPIO27           Touch interrupt (optional, can poll instead)

SD Card Slot (Optional):
SD_CS                   GPIO13           SD card chip select
SD_MOSI                 GPIO23           Shared with display
SD_MISO                 GPIO19           Shared with display
SD_SCK                  GPIO18           Shared with display

Wiring Notes:
- Use SHORT jumper wires (6-8cm max) for SPI signals to reduce noise
- Keep MOSI, MISO, SCK, and CS lines parallel and close together
- Test continuity with multimeter before powering on
- The module has onboard 3.3V regulator, so 5V or 3.3V power works
- For best results, use 3.3V directly from ESP32-S3
```

**Physical Wiring Order** (recommended sequence):
1. Connect GND first (establishes common ground)
2. Connect VCC (power)
3. Connect CS, RESET, DC (control signals)
4. Connect MOSI, MISO, SCK (SPI data lines)
5. Connect LED (backlight)
6. Connect touch pins if using touch
7. Test with multimeter before power-on

### SPI1 Bus - CC1101 433MHz RF Module

```
ESP32-S3 to CC1101 433MHz RF Transceiver (SPI1 Bus):

CC1101 Pin       ESP32-S3 GPIO    Notes
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
VCC              3.3V (+) Rail    Power (3.3V ONLY! 5V will destroy it!)
GND              GND (-) Rail     Ground
MOSI             GPIO13           Master Out Slave In (data to CC1101)
MISO             GPIO12           Master In Slave Out (data from CC1101)
SCK              GPIO14           SPI clock (note: different from display!)
CS (CSN)         GPIO5            Chip Select (active LOW)
GDO0             GPIO25           Interrupt/RX data (REQUIRED for operation)
GDO2             GPIO26           Optional status output

⚠️ CRITICAL SAFETY WARNINGS:
- CC1101 is 3.3V ONLY! Connecting 5V will permanently damage it!
- Verify voltage with multimeter before connecting VCC
- GDO0 MUST be connected for interrupt-driven TX/RX
- Without GDO0, module will not function properly

Antenna Connection:
- Solder 17.3cm straight wire to ANT pad for 433MHz quarter-wave
- For 315MHz: use 23.8cm wire
- For 915MHz: use 8.2cm wire
- Use solid-core wire from ELEGOO kit
- Keep antenna away from power wires to reduce noise

Wiring Notes:
- Use separate SPI bus (SPI1) from display (SPI3) to avoid conflicts
- Add 10µF capacitor between VCC and GND near the module (reduces power noise)
- Keep wiring short and neat
- Test with multimeter before powering on
```

**Antenna Construction** (433MHz):
```
Materials:
- Solid-core wire from ELEGOO kit
- Wire strippers
- Ruler
- Soldering iron and solder

Steps:
1. Cut solid-core wire to 17.3cm length (6.8 inches)
2. Strip 5mm insulation from one end
3. Tin the stripped end with solder
4. Solder to ANT pad on CC1101 module
5. Ensure antenna stands vertically or at 45° angle
6. Keep antenna away from other components

Why 17.3cm?
- Quarter-wavelength for 433MHz
- Formula: λ/4 = (300,000,000 / frequency) / 4
- For 433MHz: (300,000,000 / 433,000,000) / 4 = 0.173m = 17.3cm
```

## 🛠️ Step-by-Step Build Instructions

### Step 1: Prepare Your Workspace (15 minutes)

1. **Clear a large, well-lit workspace**
   - At least 2 feet × 2 feet of clear space
   - Good overhead lighting
   - Anti-static mat (if available)
   - Nearby power outlet for laptop

2. **Organize components**
   - Separate all components by type
   - Keep small parts in containers
   - Label resistors by value
   - Keep datasheet/documentation nearby

3. **Test tools**
   - Verify multimeter batteries
   - Test soldering iron (if needed)
   - Ensure USB cable works
   - Have spare jumper wires ready

4. **Safety check**
   - No liquids near workspace
   - Fire extinguisher nearby (soldering)
   - Good ventilation (for soldering)
   - Clear escape path

### Step 2: Verify Components (20 minutes)

1. **Check ESP32-S3 board**
   - [ ] Inspect for physical damage
   - [ ] Verify all pins are straight
   - [ ] Check USB-C connector
   - [ ] Look for any shorts with multimeter
   - [ ] Verify 3.3V regulator is present

2. **Check DollaTek Display**
   - [ ] Inspect LCD screen (no cracks)
   - [ ] Verify all pins are labeled
   - [ ] Check for bent pins
   - [ ] Test touch pen response (gently)
   - [ ] Verify SD card slot is clear

3. **Check CC1101 module**
   - [ ] ⚠️ CRITICAL: Verify it's a 3.3V module!
   - [ ] Inspect antenna connector
   - [ ] Check all pins are present
   - [ ] Verify crystal oscillator is intact
   - [ ] No visible damage to RF components

4. **Check resistors**
   - [ ] Identify 4.7kΩ resistors (Yellow-Violet-Red-Gold)
   - [ ] Identify 330Ω resistors (Orange-Orange-Brown-Gold)
   - [ ] Test with multimeter to confirm values
   - [ ] Set aside in labeled container

5. **Check LEDs**
   - [ ] Identify anode (long leg) and cathode (short leg)
   - [ ] Test with multimeter diode mode
   - [ ] Verify colors are distinct

### Step 3: Install Power Rails (15 minutes)

1. **Connect ESP32-S3 to breadboard**
   ```
   - Place ESP32-S3 straddling the center gap
   - Ensure it sits firmly (no wobbling)
   - Pins should align with rows on both sides
   - Leave space above and below for wiring
   ```

2. **Wire 3.3V power distribution**
   ```
   Step-by-step:
   1. Identify 3.3V pin on ESP32-S3 (check pinout diagram)
   2. Use RED jumper wire from 3.3V pin to [+] rail (left side)
   3. Use RED jumper wire to bridge [+] rails (left to right)
   4. Verify with multimeter: Should read 0Ω resistance
   ```

3. **Wire GND distribution**
   ```
   Step-by-step:
   1. Identify GND pins on ESP32-S3 (multiple available)
   2. Use BLACK jumper wire from GND pin to [-] rail (left side)
   3. Use BLACK jumper wire to bridge [-] rails (left to right)
   4. Verify with multimeter: Should read 0Ω resistance
   5. CRITICAL: Test for shorts between [+] and [-] rails
      - Multimeter should read >1MΩ (open circuit)
      - If short detected, find and fix before continuing!
   ```

4. **Add power decoupling (recommended)**
   ```
   - Place 10µF capacitor across [+] and [-] rails near ESP32-S3
   - Capacitor positive leg to [+], negative leg to [-]
   - This reduces power supply noise
   ```

### Step 4: Install I2C Pull-up Resistors (10 minutes)

**CRITICAL STEP - Required for future I2C devices!**

```
Physical Installation:

1. Locate GPIO21 (SDA) and GPIO22 (SCL) on ESP32-S3

2. Install 4.7kΩ resistor for SDA:
   - One leg to [+] 3.3V rail
   - Other leg to GPIO21 (SDA)
   - Bend legs to fit breadboard holes
   - Push firmly into place

3. Install 4.7kΩ resistor for SCL:
   - One leg to [+] 3.3V rail
   - Other leg to GPIO22 (SCL)
   - Ensure good contact

4. Verify installation:
   - Multimeter from GPIO21 to 3.3V: should read ~4.7kΩ
   - Multimeter from GPIO22 to 3.3V: should read ~4.7kΩ
   - Multimeter from GPIO21 to GND: should read ~4.7kΩ (through resistor)
   - Multimeter from GPIO22 to GND: should read ~4.7kΩ (through resistor)

Why This Matters:
- Without pull-ups, I2C communication will fail
- Many devices in later phases use I2C
- Pull-ups ensure signal integrity
- Industry standard is 4.7kΩ for I2C
```

### Step 5: Wire Status LEDs (15 minutes)

1. **Install Red Error LED**
   ```
   Physical Placement:
   - Choose a row near the edge of breadboard (easy to see)
   - Insert LED with correct polarity:
     - Long leg (anode) goes to resistor
     - Short leg (cathode) goes to GND rail

   Wiring:
   1. Insert red LED into breadboard
   2. Connect 330Ω resistor from LED anode to empty row
   3. Jumper wire from resistor to ESP32-S3 GPIO32
   4. Connect LED cathode (short leg) to [-] GND rail
   5. Verify: Multimeter continuity from GPIO32 to LED to GND
   ```

2. **Install Blue/Green Activity LED**
   ```
   Physical Placement:
   - Place next to red LED for easy comparison
   - Same polarity rules apply

   Wiring:
   1. Insert blue/green LED into breadboard
   2. Connect 330Ω resistor from LED anode to empty row
   3. Jumper wire from resistor to ESP32-S3 GPIO33
   4. Connect LED cathode (short leg) to [-] GND rail
   5. Verify: Multimeter continuity from GPIO33 to LED to GND
   ```

3. **Test LEDs (before connecting display)**
   ```
   Pre-flight LED Test:
   1. Connect ESP32-S3 to laptop via USB-C
   2. Upload simple LED blink code (see firmware section below)
   3. Verify both LEDs blink in sequence
   4. If LEDs don't light:
      - Check polarity (flip LED if needed)
      - Verify resistor value (should be 330Ω)
      - Test LED with multimeter diode mode
      - Check GPIO pin connections
   ```

### Step 6: Wire DollaTek ILI9341 Display (45 minutes)

**Take your time with this step - it's complex!**

1. **Plan display placement**
   ```
   - Display is large and will occupy rows 26-50 (approx)
   - Position so wires can reach ESP32-S3 comfortably
   - Ensure display doesn't block status LEDs
   - Leave room for CC1101 module above or below
   ```

2. **Wire power first**
   ```
   CRITICAL: Do this before any signal wires!

   1. VCC pin on display → [+] 3.3V rail (RED wire)
   2. GND pin on display → [-] GND rail (BLACK wire)
   3. LED pin (backlight) → [+] 3.3V rail (RED wire)
      - For PWM dimming, connect to GPIO instead
   4. VERIFY with multimeter:
      - VCC to GND should show ~0V (power is off)
      - No shorts between VCC and GND
   ```

3. **Wire SPI control signals**
   ```
   Use SHORT jumper wires (6-8cm preferred)!

   CS (Chip Select):
   - Display CS pin → ESP32-S3 GPIO15
   - Wire color: ORANGE (recommended)

   RESET:
   - Display RESET pin → ESP32-S3 GPIO4
   - Wire color: YELLOW (recommended)

   DC (Data/Command):
   - Display DC pin → ESP32-S3 GPIO2
   - Wire color: GREEN (recommended)
   ```

4. **Wire SPI data lines**
   ```
   KEEP THESE WIRES PARALLEL AND CLOSE TOGETHER!

   MOSI (Master Out Slave In):
   - Display MOSI/SDI pin → ESP32-S3 GPIO23
   - Wire color: BLUE (recommended)

   MISO (Master In Slave Out):
   - Display MISO/SDO pin → ESP32-S3 GPIO19
   - Wire color: PURPLE (recommended)

   SCK (Clock):
   - Display SCK pin → ESP32-S3 GPIO18
   - Wire color: WHITE/GRAY (recommended)
   ```

5. **Wire touch controller (optional but recommended)**
   ```
   Touch Controller Pins:

   T_CS (Touch Chip Select):
   - Display T_CS pin → ESP32-S3 GPIO14
   - Wire color: PINK (recommended)

   T_CLK, T_DIN, T_DO:
   - These share SPI bus with display (already connected)
   - No additional wiring needed

   T_IRQ (Touch Interrupt - optional):
   - Display T_IRQ pin → ESP32-S3 GPIO27
   - Can poll touch instead of using interrupt
   ```

6. **Wire SD card slot (optional)**
   ```
   If using SD card for data logging:

   SD_CS (SD Chip Select):
   - Display SD_CS pin → ESP32-S3 GPIO13
   - Wire color: BROWN (recommended)

   SD_MOSI, SD_MISO, SD_SCK:
   - These share SPI bus with display (already connected)
   ```

7. **Double-check all display connections**
   ```
   Verification Checklist:
   [ ] VCC → 3.3V rail
   [ ] GND → GND rail
   [ ] LED → 3.3V rail
   [ ] CS → GPIO15
   [ ] RESET → GPIO4
   [ ] DC → GPIO2
   [ ] MOSI → GPIO23
   [ ] MISO → GPIO19
   [ ] SCK → GPIO18
   [ ] T_CS → GPIO14 (if using touch)
   [ ] T_IRQ → GPIO27 (if using interrupt)
   [ ] SD_CS → GPIO13 (if using SD card)

   Continuity Test:
   - Use multimeter to verify each connection
   - Check for shorts between adjacent pins
   - Ensure no pins are bridged accidentally
   ```

### Step 7: Build and Install CC1101 Antenna (30 minutes)

1. **Prepare antenna wire**
   ```
   Materials:
   - Solid-core wire from ELEGOO kit (22AWG or 24AWG)
   - Wire strippers
   - Ruler or measuring tape
   - Soldering iron and solder

   Steps:
   1. Measure exactly 17.3cm of wire (6.81 inches)
   2. Cut cleanly with wire cutters
   3. Strip 5mm (0.2 inches) from one end
   4. Clean stripped end with isopropyl alcohol
   5. Tin the stripped end with solder (thin coating)
   ```

2. **Solder antenna to CC1101**
   ```
   Soldering Procedure:
   1. Secure CC1101 module (use helping hands or vice)
   2. Identify ANT pad on CC1101 PCB
   3. Clean ANT pad with isopropyl alcohol
   4. Apply small amount of flux to ANT pad
   5. Heat pad with soldering iron (350°C)
   6. Touch solder to pad until it flows
   7. Insert tinned wire end into solder
   8. Remove iron and let cool (don't move wire!)
   9. Verify connection with gentle tug
   10. Inspect solder joint (should be shiny and smooth)

   Quality Check:
   - Solder joint should be concave (not balled up)
   - Wire should be firmly attached
   - No cold solder joints (dull, grainy appearance)
   - Antenna stands straight up or at 45° angle
   ```

3. **Test antenna connection**
   ```
   Multimeter Test:
   - Continuity from ANT pad to wire tip (should beep)
   - Resistance should be near 0Ω
   - No shorts to adjacent pads
   ```

### Step 8: Wire CC1101 RF Module (40 minutes)

**CRITICAL: CC1101 is 3.3V ONLY! 5V will destroy it instantly!**

1. **Position CC1101 on breadboard**
   ```
   Placement Strategy:
   - Keep CC1101 away from ESP32-S3 (reduce interference)
   - Position so antenna doesn't cross power wires
   - Ensure good access to all pins
   - Leave room for future nRF24L01+ module
   ```

2. **Add power decoupling capacitor (highly recommended)**
   ```
   Why: CC1101 draws power spikes during TX, needs clean power

   Installation:
   1. Place 10µF capacitor next to CC1101 module
   2. Positive leg to VCC pin of CC1101
   3. Negative leg to GND pin of CC1101
   4. Keep leads short (< 5mm)
   ```

3. **Wire CC1101 power**
   ```
   ⚠️ VERIFY 3.3V WITH MULTIMETER FIRST!

   1. Measure voltage at [+] rail with multimeter
   2. Should read 3.3V (±0.1V)
   3. If >3.6V, STOP! Do not connect CC1101!
   4. If voltage OK:
      - CC1101 VCC pin → [+] 3.3V rail (RED wire)
      - CC1101 GND pin → [-] GND rail (BLACK wire)
   ```

4. **Wire CC1101 SPI signals**
   ```
   Use different SPI bus from display to avoid conflicts!

   MOSI:
   - CC1101 MOSI pin → ESP32-S3 GPIO13
   - Wire color: BLUE

   MISO:
   - CC1101 MISO pin → ESP32-S3 GPIO12
   - Wire color: PURPLE

   SCK:
   - CC1101 SCK pin → ESP32-S3 GPIO14
   - Wire color: WHITE/GRAY

   CS (CSN):
   - CC1101 CS/CSN pin → ESP32-S3 GPIO5
   - Wire color: ORANGE
   ```

5. **Wire CC1101 control signals**
   ```
   CRITICAL: GDO0 MUST be connected!

   GDO0 (RX/TX Interrupt):
   - CC1101 GDO0 pin → ESP32-S3 GPIO25
   - Wire color: GREEN
   - This is REQUIRED for CC1101 operation!

   GDO2 (Status - optional):
   - CC1101 GDO2 pin → ESP32-S3 GPIO26
   - Wire color: YELLOW
   - Optional but recommended for debugging
   ```

6. **Verify CC1101 wiring**
   ```
   Verification Checklist:
   [ ] VCC → 3.3V rail (verified with multimeter!)
   [ ] GND → GND rail
   [ ] MOSI → GPIO13
   [ ] MISO → GPIO12
   [ ] SCK → GPIO14
   [ ] CS → GPIO5
   [ ] GDO0 → GPIO25 (REQUIRED!)
   [ ] GDO2 → GPIO26 (optional)
   [ ] 10µF capacitor across VCC and GND
   [ ] Antenna soldered and standing upright
   [ ] No shorts between VCC and GND
   [ ] No shorts between adjacent pins
   ```

**CRITICAL: Do this before powering on!**

1. **Visual inspection**
   ```

   ```

   3. Test ALL connections in pin assignment table

   Test power rails:
   1. [+] rail left side → [+] rail right side (should beep)
   2. [-] rail left side → [-] rail right side (should beep)
   3. [+] rail → [-] rail (should NOT beep, open circuit)
   ```

   ```

   1. Multimeter in resistance mode (Ω)
   2. Test between [+] and [-] rails
   3. Should read >1MΩ (open circuit)

   5. Test between adjacent GPIO pins
   6. Should read open circuit (>1MΩ)

## 🚨 Troubleshooting Common Issues

### Issue: Nothing works, no power

**Symptoms:**
- No LEDs light up
- Display backlight doesn't turn on
- Serial console shows nothing

**Solutions:**
1. Check USB cable (must support data, not charge-only)
2. Try different USB port on laptop
3. Verify ESP32-S3 is seated correctly in breadboard
4. Check for shorts between [+] and [-] rails
5. Measure voltage at 3.3V rail (should be 3.3V)

### Issue: Display backlight on but no text

**Symptoms:**
- Display glows white/blue
- No Bruce branding appears
- Serial console works fine

**Solutions:**
1. Check all SPI wiring (MOSI, MISO, SCK, CS, DC, RESET)
2. Verify pin numbers in platformio.ini match your wiring
3. Try different TFT_eSPI settings
4. Ensure display is ILI9341 driver (not other type)
5. Check DC pin connection (common issue)

### Issue: CC1101 not detected (VERSION reads 0x00 or 0xFF)

**Symptoms:**
- Serial console shows "CC1101 not detected"
- VERSION register reads 0x00 or 0xFF
- Red LED turns on

**Solutions:**
1. ⚠️ VERIFY 3.3V power with multimeter (5V destroys CC1101!)
2. Check all SPI wiring (MOSI, MISO, SCK, CS)
3. Verify GDO0 is connected (required!)
4. Add 10µF capacitor across VCC and GND
5. Try lower SPI frequency (500kHz)
6. Check for bent pins on CC1101
7. Verify CC1101 is not damaged

### Issue: LEDs don't light or very dim

**Symptoms:**
- LEDs are dim or don't light at all
- Other components work fine

**Solutions:**
1. Check LED polarity (long leg = anode = positive)
2. Verify resistor value is 330Ω (not 330kΩ!)
3. Test LED with multimeter diode mode
4. Check GPIO pin connections
5. Verify GPIO pins aren't already in use

### Issue: I2C devices not working (future phases)

**Symptoms:**
- I2C scan finds no devices
- I2C communication fails

**Solutions:**
1. ⚠️ VERIFY 4.7kΩ pull-up resistors are installed!
2. Check SDA (GPIO21) and SCL (GPIO22) connections
3. Measure voltage on SDA and SCL (should be 3.3V when idle)
4. Verify pull-ups are to 3.3V, not GND
5. Check for I2C address conflicts

### Issue: ESP32-S3 keeps resetting or crashing

**Symptoms:**
- Boot loop (restarts constantly)
- Random crashes
- Watchdog resets

**Solutions:**
1. Check power supply (may be insufficient current)
2. Use powered USB hub (laptop USB may be weak)
3. Add 10µF capacitor across 3.3V and GND rails
4. Disable WiFi in code (uses a lot of power)
5. Check for shorts in wiring
6. Reduce SPI clock speeds

### Issue: Serial console garbled or weird characters

**Symptoms:**
- Random characters instead of text
- Some text readable, some garbled
- Chinese/Japanese characters

**Solutions:**
1. Check baud rate is 115200
2. Try different baud rates (921600, 57600, 9600)
3. Verify USB cable supports data
4. Try different USB cable
5. Check for ground loops
6. Add decoupling capacitor near USB connector
