## What is BRUCE?

BRUCE is Flipper Zero's powerful big brother - a professional-grade wireless security research platform featuring multi-processor architecture, extensive RF capabilities, and modular plugin-based firmware.

### Key Features

- **Multi-Processor Architecture**: ESP32-S3 + ESP32-C6 + RP2040
- **Extensive RF Capabilities**: WiFi 6, BLE 5.3, Sub-GHz (315/433/868/915MHz), LoRa, NFC/RFID
- **Integrated Battery**: 18650 cell with charging circuit
- **Touchscreen Display**: 2.8" TFT with professional UI
- **Modular Plugin System**: Hot-loadable firmware plugins

## Operating Modes

- **Sidekick Mode** 🐬↔️🦈: Works as peripheral to Flipper Zero
- **Solo Hunter Mode** 🦈: Standalone operation with touchscreen UI
- **Hybrid Mode** 🐬🦈: Best of both worlds (recommended)

## Why BRUCE?

Solves BFFB's SPI bus conflict issues through intelligent multi-bus architecture with 3 isolated SPI buses:

- **SPI1**: Triple CC1101 modules (315/433/915MHz)
- **SPI2**: nRF24L01+, SX1276 LoRa, W25Q512 Flash, PN532 NFC
- **SPI3**: MicroSD card (dedicated)
